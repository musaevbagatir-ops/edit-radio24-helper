# Radio24 AdHelper

Помощник для редактирования объявлений на Radio24 в Online RP. Это скрипт на Lua для MoonLoader

Установленные MoonLoader, SAMPFUNCS, SAMP.Lua и mimgui. Игра с проектом Online RP.

## Как установить

1. Скачайте архив репозитория: зелёная кнопка Code, затем Download ZIP.
2. Из архива скопируйте файл radio24_helper.lua Version.txt папку radio24 и config в папку moonloader вашей игры.
3. Запустите игру. Скрипт сам создаст нужные файлы настроек.
4. Если игра уже запущена, перезагрузите скрипты сочетанием Ctrl+R.

## Как пользоваться

Введите в чате /edit или /adm, откроется окно хелпера. Выберите объявление из списка, проверьте предложенный вариант и нажмите Принять. Справка по всем функциям открывается командой /adfaq.

## Основные команды

/adm открыть или закрыть окно
/adfix текст разобрать любой текст объявления
/adfaq справка
/adh включить или выключить хелпер
/adtest проверка алгоритма на примерах
/adupd проверить и установить обновление

## Обновления

Хелпер сам проверяет новую версию при заходе в игру. Если она есть, напишет об этом в чат. Установить её можно командой /adupd.
